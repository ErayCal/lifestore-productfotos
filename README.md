# lifestore-productfotos

Productafbeeldingen voor de bol.com-listings van LifeStoreCP.

Deze repo is openbaar omdat bol.com de afbeeldingen via een publieke URL moet
kunnen ophalen bij het aanleveren van productcontent. Er staat verder niets in:
geen code, geen sleutels, geen klantgegevens.

Indeling: `<temu-product-id>/<kleur>/<nummer>-<soort>.jpg` en per product een
`maattabel.jpg`.
